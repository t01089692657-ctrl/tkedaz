# 坦克大战 · Tank Battle

一个单文件 HTML5 Canvas 复刻的经典坦克大战小游戏，复古街机 CRT 风格，无任何外部依赖。

直接用浏览器打开 `index.html` 即可游玩。

## 玩法

- 消灭每关 20 辆敌方坦克，同时保卫基地之鹰——基地被击毁或生命耗尽则游戏结束
- 敌军有四种：普通、快速、强力（快弹）、装甲（4 发才能击毁）
- 每关第 4 / 11 / 18 辆敌军为闪烁奖励坦克，击毁后掉落道具：
  - **盾** 无敌护盾 · **星** 火力升级（射速 → 双发 → 穿钢）· **雷** 全屏清敌 · **冻** 冻结敌军 · **命** 加一条命
- 关卡无限循环，敌军逐关增多变强

## 操作

| 动作 | 按键 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 射击 | 空格 / J |
| 暂停 | P |
| 声音开关 | M |
| 开始 / 重开 | 回车 |

移动端自带虚拟方向键和开火按钮。
