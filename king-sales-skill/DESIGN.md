# 方案说明：King 销冠自动回复 Skill 的全部思路与用途

> 本文档回答四个问题：这个 Skill 是什么、它是怎么造出来的、每个文件为什么存在、以及怎么用怎么养。
> 版本：v1.1（2026-07-05）

---

## 一、这是什么，解决什么问题

**一句话**：把「King 的销冠孵化器知识库」+「真实 WhatsApp 成交对话」蒸馏成一个 AI 技能包，挂进销冠工作台后，AI 可以模仿销冠 King 的打法和语气自动回复 WhatsApp 客户，把销售从重复的前端聊天中解放出来，只在关键环节（报价、拉群、收款）介入。

**它覆盖的业务**：中国移动房屋工厂（JC CABIN，产品线 T/A/P/F/C/D/K 七系列）的外贸销售，客户来自 Facebook/TikTok 等社媒广告，语言以英语/西语为主，成交场景为 WhatsApp 私聊 + 拉群报价。

**AI 的职责边界**（这是整个设计的核心决策）：
- **AI 做**：开场、筛选提问、客户类型判断、初步选型推荐、常规异议应对、沉默跟进、把客户推进到"可报价状态"
- **AI 不做**（转人工）：报运费/DDP总价、折扣、付款条款、独家代理、认证承诺、投诉处理、拉群后的正式报价
- 依据：知识库里明确写了"助理不深度谈价格、不聊折扣、不承诺认证"；真实对话里 King 的分工也是"前端归 King，报价归产品经理（Zoey）"。AI 完全对齐这个已经被验证的团队分工，而不是发明新流程。

## 二、原料：用了什么数据

| 数据 | 规模 | 贡献 |
|---|---|---|
| 销冠孵化器1.0知识库（22份Word） | 33万字符 | 方法论主体：产品知识、客户画像与分级、筛选SOP、四类客户成交路径、话术库、金句库、故事库 |
| WhatsApp 真实对话 ×6 | 菲律宾/墨西哥/爱尔兰/波兰/萨尔瓦多/洪都拉斯 | 真实语气与节奏、拉群报价实况、定制核价实况、以及一个真实失误案例（反面教材） |
| P20 官方报价单 PDF | 1份 | 最可信的产品参数与价格口径（FOB $7,300 含配置明细） |

**为什么两种数据都必需**：知识库告诉 AI"应该怎么打"（策略层），聊天记录告诉 AI"实际怎么说"（表达层）。只有知识库会像教科书一样说话；只有聊天记录会缺少完整方法论。两者交叉验证过的内容（如 A3=64㎡、P20=37㎡、开场白模板）可信度最高。

## 三、构建方法：从 34 万字到一个技能包

1. **并行蒸馏**：22 份文档按主题分给 5 路并行分析（产品知识 / 画像标签背调 / 开场筛选 / 成交SOP / 话术金句故事），每路只保留"AI 回复时用得上的东西"：硬数据、话术原文（中英西保留原文不改写）、可执行规则、红线，删除培训励志和内部管理内容。
2. **风格与知识分离**：聊天记录单独提炼成 style.md（语言、气泡节奏、表情规则、真实话术样本），与知识类文件分开——产品价格会变、话术会更新，但"说话像不像 King"是独立维度，分开维护互不污染。
3. **反面教材入库**：真实对话里波兰客户两次追问"当地有没有实景房"被"我们卖遍全球"搪塞导致不满——这类失误被显式写成禁止规则 + 正确替代话术，AI 不重复人犯过的错。
4. **主文件轻、参考文件厚（渐进式加载）**：SKILL.md 控制在几千字（每次调用都读），话术库/SOP等 7 个参考文件共约 20 万字符（按需读取）。这样既不撑爆上下文，又保证细节随取随用。
5. **回归测试后上线**：用真实聊天中的 4 个场景（新客开场 / 爱尔兰DDP询价 / 波兰实景房追问 / 民宿客户比价砍价）测试输出，验证格式契约、风格贴合度、红线执行，发现问题（提问与承诺混气泡）修入规则后定版。

## 四、架构：每个文件为什么存在

```
king-sales-skill/
├── SKILL.md            ← 大脑：每次回复必读
├── DESIGN.md           ← 本文档：思路与用途说明（给人看，AI 不读）
├── README.md           ← 快速上手（给人看）
└── references/         ← 知识库：按需查阅
    ├── style.md        ← 怎么说话（每次回复必读）
    ├── frontend.md     ← 阶段①②：开场白、社媒回复、跟进节奏
    ├── personas.md     ← 判断对象：六类客户、A/B/C/D分级、标签、背调
    ├── products.md     ← 卖什么：七大产品线、FAQ、产品红线、P20实测
    ├── sop-flows.md    ← 怎么推进：四类客户成交路径、报价策略、视频SOP
    ├── scripts-trust.md← 怎么化解：异议话术、38条金句、22个信任故事
    └── deal-cases.md   ← 照着打：真实成交对话逐步拆解
```

**SKILL.md 的内部逻辑**（AI 每次回复的思考顺序）：

```
收到客户消息
→ ① 判断语言（英/西跟随客户）
→ ② 判断客户类型（终端/民宿/代理/中间商 ← personas.md）
→ ③ 判断阶段（7阶段状态机：开场→筛选→选型→报价→异议→推进→跟进）
→ ④ 查对应参考文件拿打法和话术
→ ⑤ 按 style.md 的风格输出 1-3 个短气泡，结尾带问题
→ 触发红线？→ 输出 @转人工 + 给人工的建议草稿
```

**七阶段状态机**是知识库"成交路径SOP"的工程化：判断依据是"还缺什么关键信息"（国家/用途/数量/进口经验/地址…），不是聊了几句。客户上来就问价也会被拉回筛选链——这正是知识库反复强调的"先筛选后报价"。

**输出契约**（工作台解析用）：
```
@状态 类型=终端 阶段=④报价 语言=EN 媒体=A3型号图册     ← 控制行
第一个气泡文本
---
第二个气泡文本
```
转人工时控制行变为 `@转人工 原因=运费核价`，正文变成给人工的建议草稿。媒体用`【媒体：…】`占位符，由工作台替换成真实图片/视频/PDF发送。

## 五、红线设计哲学：为什么 AI 不报价

三层原因：
1. **知识库规定**：助理角色本来就不深谈价格、折扣、认证——AI 是"超级助理"，不是"超级销售总监"
2. **数据事实**：价格随配置/数量/汇率/运费变化（同一 P20：单套 FOB $7,300、双套 $6,100/套、基础款口径 $5,500），AI 引用旧价格的风险远大于收益
3. **信任结构**："我去跟经理/货代确认"本身就是销冠打法的一部分（制造重视感、争取感），转人工不是 AI 的缺陷，而是复刻真实流程

所以设计为：**AI 讲逻辑（整柜装载、包含什么、为什么值），人报数字（运费、折扣、总价）**。

## 六、用途与接入方式

**用途场景**：
1. **自动回复**（目标形态）：工作台收到客户 WhatsApp 消息 → 调 AI（SKILL.md 为 system prompt，输入=客户消息+历史记录+标签）→ 解析控制行 → 自动发送或推给人工
2. **军师模式**（建议起步）：AI 只出草稿，销售一键采纳/修改后发送；同时积累"AI建议 vs 实发"对比数据
3. **新人培训**：参考文件本身就是结构化的销冠教材，新销售可直接背 deal-cases.md 和 style.md
4. **质检**：用 SKILL.md 的红线清单反向检查人工聊天记录是否踩线

**接入要点**：
- Claude Code / Agent SDK：整个文件夹放 `.claude/skills/` 即自动加载
- 自建工作台：SKILL.md 做 system prompt；references 做成按需读取的工具或 RAG，**不要全量塞上下文**
- 需要工作台侧准备：媒体库映射（占位符→真实文件）、控制行解析器、转人工通知链路、客户标签透传

## 七、怎么养：每周查漏补缺循环

```
每周：导出新聊天记录（含群聊！）
  → 对比 AI 草稿与销售实发（军师模式天然产生此数据）
  → 修改率最高的场景 = 本周补话术的优先级
  → 新异议 → scripts-trust.md；新案例 → deal-cases.md
  → 价格/型号变动 → 只改 products.md
  → 改完用 10-20 段历史对话回放，确认风格和红线没漂移
```

**数据卫生提醒**（影响未来迭代质量）：
- 关闭重要客户的"7天限时消息"（爱尔兰单里发现该设置，会持续销毁训练数据）
- 拉群报价的群聊记录一并导出（v1.0 时缺失，v1.1 靠萨尔瓦多群聊补上了报价环节）
- 联系人命名继续保持标签规范（如"CT投资萨尔瓦多Walter260629已分配zoey"），工作台可直接解析出等级/来源/国家/归属

## 八、已知局限与待补数据

| 局限 | 影响 | 补救 |
|---|---|---|
| 尚无"从开场到收定金"的全程成交记录 | 逼单⑥、成交后跟进的实战话术仍以知识库理论为主 | 补 2-3 单完整成交记录（含PI/付款环节） |
| 无丢单案例对照 | 无法从失败中提炼禁忌 | 补 1-2 个典型丢单 |
| 媒体库未建立 | 占位符无法自动替换 | 整理"型号→图/视频/PDF"清单 |
| 价格口径仅 P20 有报价单背书 | 其他型号 AI 只能讲区间和逻辑 | 各主力型号报价单入库（只进 products.md） |
| 英语市场群聊案例缺失 | 拉群话术目前西语实证、英语为同构翻译 | 补英语群聊记录 |
