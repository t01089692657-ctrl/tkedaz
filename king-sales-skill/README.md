# King 销冠自动回复 Skill

基于「King的销冠孵化器1.0知识库」（22份文档，33万字）+ 真实 WhatsApp 成交对话蒸馏而成的移动房屋外贸销售自动回复技能包。

## 文件结构

```
king-sales-skill/
├── SKILL.md                    # 主技能：角色、决策流程、阶段状态机、红线、输出契约
├── references/
│   ├── style.md                # King 真实聊天风格（从 WhatsApp 对话提炼，每次回复必读）
│   ├── frontend.md             # 开场白与前端筛选 SOP（多语言话术原文）
│   ├── personas.md             # 六类客户画像、A/B/C/D 分级、双标签体系、背调11招
│   ├── products.md             # 六大产品线知识、选型逻辑、FAQ 英文话术、12条产品红线
│   ├── sop-flows.md            # 四类客户成交路径 SOP + 报价策略 + 视频电话展厅 SOP
│   ├── scripts-trust.md        # 全场景话术库、38条高信任金句、22个信任故事
│   └── deal-cases.md           # 真实成交对话逐步拆解（拉群报价/整柜劝购/定制核价）
├── DESIGN.md                   # 全部思路与用途说明（必读）
└── README.md
```

## 接入销冠工作台

1. **Claude Code / Agent SDK**：把整个 `king-sales-skill/` 文件夹放到 `.claude/skills/` 目录即可自动加载。
2. **自建工作台（API 调用）**：把 `SKILL.md` 作为 system prompt 主体；references 按 SKILL.md 末尾的索引表按需注入（推荐做成工具/RAG，让模型自己决定读哪个文件，不要全部塞进上下文）。
3. **每次调用输入**：客户最新消息 + 该客户历史聊天记录 +（如有）工作台里的客户标签。
4. **输出契约**（工作台需解析）：
   - 第 1 行控制行：`@状态 类型=… 阶段=… 语言=… 媒体=…` 或 `@转人工 原因=…`
   - 正文：1-3 个消息气泡，用 `---` 分隔，直接可发送
   - 媒体占位符：`【媒体：…】`，由工作台替换为实际图片/视频后发送

## 建议的上线路径

1. **军师模式**（第1-2周）：AI 生成回复候选，销售人工确认后发送，同时记录"采纳/修改/拒绝"
2. **半自动**：筛选期消息（阶段①②）自动发送，报价及之后人工确认
3. 全自动前必须把"转人工"链路跑通（运费核价、付款、投诉、大单）

## 持续查漏补缺（每周循环）

1. 导出本周新聊天记录 → 对比"AI 建议 vs 销售实际发送"，修改率高的场景优先补话术
2. 出现知识库没有的新异议 → 追加到 `scripts-trust.md` 对应分类
3. 产品价格/型号变动 → 只改 `products.md`，不动其他文件
4. 每次修改后用 10-20 段历史对话回放测试，确认风格和红线没有漂移

## 红线提醒（已写入 SKILL.md，此处再强调）

- 绝不当场报 DDP 总价/运费——必走"要地址→转人工核价"流程
- 价格、折扣、付款条款、独家代理：AI 一律不承诺，转人工
- 知识库里没有的参数/案例/认证：不编造，转人工核实
