# King 客户评级 Skill

独立的客户评级与筛选技能，基于「King 销冠孵化器」分级体系。与自动回复 Skill 分离部署，可单独使用。

## 三种用途

1. **新线索分级**：把聊天记录丢进来 → 得到等级、类型、标签串、建议动作
2. **老客户盘点**（本技能的重点扩展）：批量重评已成交客户的复购优先级、沉睡客户的激活优先级
3. **CRM 标签生成**：输出符合团队命名规范的标签串（如 `AF民宿墨西哥待报价`），可直接写回工作台

## 文件结构

```
king-customer-grading/
├── SKILL.md                        # 评级流程、输出格式、评级红线
├── references/
│   ├── grading-rules.md            # 九级标准、六类客户细则、标签命名规范、意向信号
│   └── old-customers.md            # 老客户重评：复购评估、沉睡激活矩阵、八种处置
├── King客户评级Skill-使用说明.docx    # 给使用人看的 Word 说明
└── README.md
```

## 接入方式

- Claude Code / Agent SDK：文件夹放 `.claude/skills/` 自动加载
- 自建工作台：SKILL.md 做 system prompt，两个 references 全量注入即可（总量小，无需 RAG）
- 输入：客户聊天记录/资料，单个或批量；老客户盘点时附上最后联系时间和历史成交信息
- 输出：`@评级` 控制行 + 评级卡（单个）或评级总表（批量），工作台可解析入库

## 与自动回复 Skill 的配合

两者独立可用；配合使用时：自动回复 Skill 聊完的对话 → 定期喂给本技能重评 → 评级结果写回客户标签 → 自动回复 Skill 读标签调整打法（A级提速、S级只做节点激活）。
