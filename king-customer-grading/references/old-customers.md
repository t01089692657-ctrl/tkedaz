# 老客户重评与激活筛选规则

> 适用：CRM 里已有记录的客户盘点——包括已成交客户（V系）和长期未联系的沉睡客户。
> 规则来源标注：S/V/V2/V3 定义、激活话术、升降级条件 = **公司规则原文**；"卡点时效性 × 信息完整度 × 沉睡时长"激活优先级矩阵 = **基于公司SOP的补充推导**（公司规则未细化老客户重评，此矩阵由 S类定义 + 卡点判断表 + 信息完整度标准组合而成）。
> 底层认知（来自故事库）：**不回 ≠ 不要**。真实买家也会因为忙、等合伙人/土地/资金/审批而中断，需求还在，只是时间窗口关了。激活不是每天问 "Are you still interested?"（那是骚扰），而是刷高质量存在感，等窗口重开时你还在他视野里。
> **激活话术一律优先引用公司激活话术库**（`decision-scripts.md` 第二节，13个场景各3轮，含升降级条件）：按客户"当时卡点+类型"选对应场景，从第1轮开始发。

## 一、已成交客户（V / V2 / V3）复购评估

**评估四维度**：
1. **客户类型的复购天性**：民宿/营地/度假村 = 扩建复购高（一期成功必有二期）；代理商 = 周期性补货；建筑商 = 项目型间歇复购；个人自住 = 复购低但**转介绍价值高**
2. **上次成交距今时长**：民宿类 3-6 个月是二期窗口（一期运营见效期）；代理商按其销售周期
3. **交付体验**：交付顺利无售后纠纷 → 直接推新品/二期；有过售后问题 → 先回访解决满意度再谈复购
4. **历史对话中的扩展信号**：当时是否提过"先做X套试试"、"以后扩大"、土地还有余量、问过别的系列

**输出复购优先级**：
- **高**：民宿/代理型 + 交付满 3 个月 + 当时有扩建表述 → 主动问项目运营情况+推二期方案
- **中**：交付顺利但无扩建信号 → 新品/案例定期触达 + 请求转介绍
- **低**：个人自住单套 → 年度问候 + 转介绍话术
- V2/V3 一律高优先级维护，节点性业务回顾

**已成交客户激活话术方向**：问运营/入住反馈（民宿）、问销售情况和库存（代理）、新品首发优先权、老客户返点/转介绍政策。

## 二、未成交沉睡客户重评（核心流程）

对每个沉睡客户依次判定四步，得出激活优先级：

### 第1步：还原当时的等级与卡点
从历史记录找出：当时评到什么级、最后一次对话停在哪个阶段、**具体卡点**是什么（价格/运费/土地/审批/资金/家人合伙人决策/比价/无进口经验/失联无原因）。找不到明确卡点的，按"信息完整度"兜底判断。

### 第2步：卡点时效性判断（最关键的一步）
- **会自然解决的卡点（时间型）→ 高激活价值**：审批进行中、等资金到位、土地在谈、项目未到启动季、等合伙人决策、说过"X月再启动"
- **可被我们解决的卡点（方案型）→ 中激活价值**：运费太贵（运价会变，可更新报价激活）、配置超预算（可降配重报）、担心安装（可发新安装案例）、不信任（可发新交付案例/邀视频）
- **硬卡点（结构型）→ 低价值/归档**：预算与产品完全不匹配、没土地也没购地计划、纯比价собирал、明确说不做了

### 第3步：信息完整度加权
当时给过 **土地照片/详细地址/数量/开业时间** 的沉睡客户 ≫ 只问过价的。给过高完整度信息的客户即使沉睡半年也值得重点激活；只问过价的沉睡客户降为低频池。

### 第4步：沉睡时长分层
| 沉睡时长 | 处理 |
|---|---|
| <1 个月 | 仍在正常跟进节奏内，按原等级节奏继续 |
| 1-3 个月 | **重点激活池**：卡点时效性高的逐个定制激活 |
| 3-6 个月 | 定期案例激活（新案例/新型号/运费更新） |
| >6 个月 | 年度节点激活（新品发布/促销季/客户所在国旺季前） |

### 激活优先级判定矩阵

| 卡点时效性 \ 信息完整度 | 高（有土地/地址/数量） | 中 | 低（只问过价） |
|---|---|---|---|
| 时间型卡点 | **激活优先级：高** | 高 | 中 |
| 方案型卡点 | **高** | 中 | 低 |
| 结构型卡点 | 中（等条件变化） | 低 | 归档 |

## 三、八种沉睡状态的标准处置（来自故事库实战）

1. 只询价不给信息 → 低频沉淀
2. 问过价但无地址用途数量 → 弱意向，偶发案例
3. 有用途无土地时间 → 养着，定期发案例
4. **有土地有项目有数量但卡价格/运费/审批/安装 → 重点激活**（逐个定制激活方案）
5. 久不回突然回来 → **秒回**，直接更新价格运费带回决策（他可能也在联系别人）
6. 每次只回一点但没消失 → 约一次电话把关键问题问清
7. 明确接受不了价格且无替代空间 → 低频沉淀
8. 只要目录最低价资料、关键问题全不答 → 看市场的，不重点跟

## 四、激活方式建议（按优先级配动作）

**激活必须给"回复的理由"，禁止裸发 "Hi / Any update?"**：
- 发相似场景新案例（"和你之前考虑的方向接近"）
- 更新运费/价格（"运价最近有变化，我帮你重新核了"）
- 问项目进度（"项目现在到哪一步了？还在选款、做预算，还是在准备场地/审批？"）
- 节点提醒（客户所在国旺季/雨季前、说过的启动月份前 1-2 个月）
- 新型号/新配置首发

**激活频率红线**：单个客户激活 2 轮无回应 → 降一档处理；高价值客户最多保持月度一次高质量触达，绝不高频轰炸。

## 五、批量盘点建议

- 每月跑一遍"1-3 个月沉睡池"，每季度跑全量老客户
- 盘点输出必须落到：本周激活名单（带激活方式）、观察池、归档名单
- 客户突然回来（"Is it still available? / What is the price now?"）= 重新进入决策期或正在比价 → 立即升级重评 + 标注秒回
